# SquareLine UI Project

This artifact identifies the editable SquareLine Studio source project, themes, assets, and generated UI design used by the ESP32 LVGL application.

The current UI contains main, global settings, Wi-Fi, audio DSP, and system screens and includes controls for EQ, compressor, delay, reverb, input gain, and output level.
