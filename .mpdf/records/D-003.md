# SquareLine Project Is the Editable UI Design Source

VOX_EFX shall use the SquareLine Studio project as the editable graphical UI design source and export generated LVGL UI code for integration into the ESP32 firmware.

Application-specific behavior, hardware integration, communications, and DSP command handling remain in the ESP32 firmware rather than being treated as SquareLine-generated logic.
