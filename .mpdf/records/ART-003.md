# Teensy Audio DSP Firmware

This artifact identifies the active Teensy 4.0 firmware implementing the mono audio path, SGTL5000 audio interface, EQ processing, true-bypass slot structure, ESP32 command handling, and telemetry.

Compressor, reverb, and delay control/state interfaces are present, but the corresponding DSP blocks remain placeholders in the current baseline.
