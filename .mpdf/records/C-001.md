# ESP32 DOIT DevKit V1

The ESP32 DOIT DevKit V1 is the selected VOX_EFX graphical UI, connectivity, and supervisory controller in the current baseline.

It runs the Arduino framework, LVGL 9.1, TFT_eSPI display interface, Wi-Fi configuration, MQTT client, touch/encoder handling, and the Teensy control interface.
