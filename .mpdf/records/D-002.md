# Effects Shall Use Explicit Bypassable Processing Slots

The VOX_EFX audio path shall organize effects as individually bypassable processing slots so an effect can be enabled or bypassed without removing the surrounding signal-chain structure.

The current baseline implements this pattern for EQ and provides equivalent slot structures for compressor, reverb, and delay.

EQ currently contains real processing. Compressor, reverb, and delay processed paths remain placeholders and shall not be considered implemented DSP until their processing blocks are completed and verified.
