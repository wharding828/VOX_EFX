# Separate UI/Supervisory Control from Real-Time Audio Processing

VOX_EFX shall partition system responsibilities between an ESP32 user-interface/supervisory controller and a Teensy 4.0 real-time audio-processing controller.

The ESP32 owns the graphical UI, touch and encoder interaction, Wi-Fi, MQTT, settings presentation, and supervisory command generation.

The Teensy owns the real-time audio signal path, DSP execution, audio hardware control, effect state, level processing, and audio telemetry.

The controllers communicate over a dedicated UART command/telemetry link.
