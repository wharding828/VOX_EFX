# 480 x 320 ST7796 Display with FT6336U Touch

The current VOX_EFX embedded user interface uses a 480 x 320 TFT configured with the ST7796 display driver and FT6336U capacitive touch controller.

The ESP32 firmware also supports rotary encoder navigation as a local input method.
