# Compressor, Reverb, and Delay Processing

VOX_EFX shall provide independently controllable compressor, reverb, and delay effects in the vocal signal chain.

The user interface and Teensy command/state interfaces already include controls for these effects. The current Teensy baseline contains bypassable placeholder slots and stored parameters, but the compressor, reverb, and delay DSP algorithms are not yet implemented and shall remain classified as incomplete until verified.
