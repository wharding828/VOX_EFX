# Remove Hard-Coded MQTT Broker Configuration

The current ESP32 firmware contains a fixed MQTT broker address (`10.0.0.19`) in source code.

Before the connectivity design is considered complete, broker configuration should be made appropriate for normal product use, such as through configurable system settings or another persistent configuration mechanism.
