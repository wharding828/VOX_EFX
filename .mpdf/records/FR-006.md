# Wi-Fi and MQTT Connectivity

VOX_EFX shall support Wi-Fi configuration through the embedded user interface and shall retain network credentials for subsequent operation.

The ESP32 shall provide MQTT-based status, diagnostic, UI-event, and UART-observation messaging so system behavior can be observed or integrated without using the UART reserved for Teensy communication.
