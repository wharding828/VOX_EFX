# ESP32-to-Teensy Command and Telemetry Link

VOX_EFX shall maintain a dedicated serial link between the ESP32 supervisory controller and the Teensy audio controller.

The ESP32 shall send user control commands for audio parameters and effect state to the Teensy, and the Teensy shall return operating telemetry and level/state information for presentation or diagnostic forwarding.
