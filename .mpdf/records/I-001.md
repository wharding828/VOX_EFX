# Complete Remaining Audio DSP Functions

The current Teensy firmware does not yet implement the full approved audio-processing scope.

Open implementation gaps include:

- compressor DSP;
- reverb DSP;
- delay DSP;
- active input-gain processing.

The ESP32 UI and Teensy command/state interfaces already expose these functions, but compressor, reverb, delay, and input gain shall not be represented as complete until the corresponding audio processing is implemented and verified.
